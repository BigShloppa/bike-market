# BikeMarket — вторичный рынок велосипедов

Курсовой проект: веб-приложение для покупки и продажи велосипедов.

## Стек

- **Backend:** Node.js, Express, PostgreSQL, Socket.IO, Nodemailer
- **Frontend:** React, Vite, React Router, Axios, Socket.IO Client
- **Инфраструктура:** Docker (PostgreSQL), Git

## Возможности

- Регистрация и вход (JWT, bcrypt)
- CRUD объявлений с загрузкой фото
- Поиск и сортировка
- Чат между покупателем и продавцом (WebSocket)
- Отзывы и рейтинг продавцов
- Публичные страницы продавцов
- Email-уведомления (Mailtrap)
- Адаптивная вёрстка
